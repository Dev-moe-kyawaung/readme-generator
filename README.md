# README Generator

A production-ready Next.js application for generating premium README.md templates with real-time preview, accessible forms, and instant deployment.

## Features

- 🎨 **Three Template Styles**: Minimalist, Data-Heavy, and Agency-Style
- ⚡ **Real-time Preview**: See changes instantly as you type
- 📋 **One-Click Copy**: Copy generated README to clipboard
- 💾 **Download**: Save as README.md file
- ♿ **Fully Accessible**: WCAG 2.1 AA compliant
- 🔍 **SEO Optimized**: Complete metadata and Open Graph support
- 🚀 **Vercel Ready**: Pre-configured for instant deployment
- 🔄 **Auto-Commit**: GitHub Actions workflow for automatic updates

## Quick Start

```bash
# Clone the repository
git clone [https://github.com/yourusername/readme-generator.git](https://github.com/yourusername/readme-generator.git)

# Install dependencies
npm install

# Run development server
npm run dev
